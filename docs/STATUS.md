# STATUS

## Objetivo atual

Construir um agente autônomo capaz de operar o computador do usuário como um operador digital.

O agente deverá poder:

- controlar mouse e teclado;
- abrir e operar aplicativos;
- acessar sites;
- navegar no navegador;
- utilizar sessões autenticadas para acessar serviços;
- visualizar a tela;
- utilizar a câmera quando autorizado;
- executar tarefas compostas em vários passos;
- receber comandos remotamente.

Os canais de controle desejados são:

- interface Web;
- WhatsApp;
- Telegram;
- Instagram.
